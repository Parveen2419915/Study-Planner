# Advanced Creative Study Planner 2025

A simple, interactive study planner built with HTML, CSS, and JavaScript.

## Features

- Create an account and log in
- Add study tasks with deadlines and priorities
- Mark tasks as complete
- Add subtasks and notes to tasks
- Delete tasks and clear completed tasks
- Sort tasks by priority, deadline, or completion status
- Earn points and unlock badges
- Daily study challenge
- Gratitude reflection
- Creative timer with custom duration
- Dark mode and color themes
- Data saved in the browser using localStorage

## How to Use

1. Open `index.html` in your browser.
2. Create an account.
3. Log in.
4. Add your study tasks and start planning.

## Technologies Used

- HTML
- CSS
- JavaScript
- localStorage

## Important Note

Accounts, tasks, points, badges, and settings are stored locally in your browser.
They are not stored on a server and will not sync between different devices or browsers.
